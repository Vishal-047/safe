SafeLane Setup

Step 1: Authenticate

Enter a GitHub Personal Access Token (PAT) with `repo` and `workflow` permissions.

Step 2: Select Repository

Select the repository where you want to install SafeLane.

Step 3: Success!

SafeLane has been successfully installed in your repository.

The workflow file `.github/workflows/safelane-gate.yml` was committed to the main branch.

It will automatically run on your next Pull Request.
